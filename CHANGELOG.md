# Changelog

Every release has an entry here. `make release` copies the entry for the current version into the release note.

## 2.2.6

- **Menu: Profile Pictures moved up.** The section is now called **Profile Pictures** (plural, like the other sections) and sits right below **Change and Edit Wallpapers**, above Home Screen Music. **Clean Up Game Names** now comes right after Home Screen Music, followed by **Redirect Where System Tiles Open**.
- **Change and Edit Wallpapers: the checkbox of Change default PS5 background** is as big as the other checkboxes (the long text beside it no longer squeezes it).
- **Change and Edit Wallpapers: folders are registered first.** In a run for many tiles, the folders are now written and registered with the console first, and the games, system tiles and default background come after. The folder install used to make the console put its own pictures back into the PS5 games, which then flashed the original background for a moment before ours each time they were highlighted.
- **Use original for many tiles tries again.** A tile whose original could not be put back (the console had the database busy) used to be skipped without a word. It is now logged, tried once more at the end, and the final log line says how many could not be put back.
- **Profile Picture has two separate parts in one menu section** (a single picture, and below it a playlist of several), each with the same layout: user tiles, USB or this device, then the new picture with **Use this picture** next to it (single picture) or **Add to the list** next to it (list part, with the list, **Use this playlist** and **Stop using this playlist**).
- **Menu: "Home Screen Folders and Tiles" is now "Folders and Tiles"**, and the number of tiles after the title is gone.
- **Menu: the new folder button** is now called "Create a New Folder" and sits below the short description in Folders and Tiles, all the way to the right.
- **Menu: Folder and Tile Options.** The folder switches (Keep folders first and the three folder page switches) moved out of Folders and Tiles into the section that was called Tile hiding options, above its two switches. That section is now called **Folder and Tile Options**, and the separate Folder options section is gone.
- **Change and Edit Wallpapers shows the tiles straight away.** The list of games and folders, with the ones that already have a background of yours, is there as soon as you open the section; you no longer have to pick a picture first. Nothing in the list is ticked to begin with.
- **Update Settings checks by itself.** Opening the section looks for a new version by itself, so the "Check for updates" button is gone, whether or not "Check for updates when Home Screen Manager starts" is on (that switch only decides about the check at start-up).
- **"Share one file between games" is gone.** On the console the drive can't link files and the home screen only reads a game's background from the game's own folder, so the option saved no space and games kept missing their background. The default background (below) does the job it was meant for. Files of it left by older builds are cleaned up as before.
- **Default background for every game and app without its own.** Games and apps that have no background entry in the database (for example the PS5 apps ps5x3 and Home Screen Manager) could not take a background. The console shows its main background file (`bg_hub_default.dds.zst` in `/system_ex/vsh_asset`, the one Prospero Themes replaces for "apps without their own image") behind all of them. **Change and Edit Wallpapers** now has its own option below **Overwrite backgrounds I've already set**, **Change default PS5 background**, with a short explanation (it is no longer in the list of system tiles). It is written and put back like a system tile background (original kept; **Use the original for the selected** with the option ticked, and **Use the original for all**, restore it). It shows only when the console has the file. To be tested on the console.
- **Filter buttons look like the action buttons.** The filter buttons (All, Games tab, Media tab, Hidden and the others like them) now have the same rounded-corner shape and size as the action buttons. They stay see-through, and the chosen one keeps its gold outline.
- **Menu colours: gold.** The update notice (the box in Update Settings and the bar at the top) is translucent gold too. The chosen filter and option buttons (All, Games tab, Media tab and the like, everywhere in the menu) are translucent gold, the main action buttons (Apply and the like) and the **Edit** buttons on games and folders are gold, to match the logo, and switches are gold when on.
- **No Browse buttons in the PS5 browser.** The Browse buttons of Home Screen Music and Profile Picture are hidden there too (they cannot open files on the console), like the others already were. On a PC or phone they are unchanged.
- **"Choose from PS5 USB Drive".** The buttons that list the pictures, songs or backups on a USB drive now say **Choose from PS5 USB Drive**, because the list is the console's drive also when the menu is open on a PC or phone.
- **"Browse this Device…".** The file pickers (the browser's own plain "Browse" / "Choose File" button) are replaced by a button of the same look as the USB one, saying **Browse this Device…**.
- **Remove buttons show an X in the PS5 browser.** The little remove buttons (the words to remove from names, the names to keep, a picture in the profile picture list) showed a question mark there because the console's browser has no such symbol; they use a plain × now. The word chips have the same shape as the buttons.
- **Folders and Tiles: a "Folders" entry above Games tab and Media tab.** It lists all your folders together, by name (there is a **Folders** filter button too). The folders are still on their tab as well, where the arrows rearrange them. In the folder editor (create and edit) the games are now listed by name, not by what you played last.
- **Change and Edit Wallpapers: a "Media tab" group.** The games and apps of the Media tab are listed in a group of their own and no longer under Games or Apps. All groups are sorted alphabetically.
- **Clean Up Game Names: the lists are alphabetical.** Both the games whose name would change and the names you have changed are sorted by name.
- **Welcome line.** Under "It only does everything you want with your PS5 home screen." the menu now says "Good Morning and Welcome, <name>" (6:00 to 11:59; "Good Afternoon" 12:00 to 17:59, "Good Evening" 18:00 to 23:59, and just "Welcome, <name>" from 0:00 to 5:59, by the clock of the phone, PC or console browser that shows the menu) with the name of the user who is signed in on the console (nothing is shown when the name can't be read), as Prospero Manager does.
- **Profile Picture layout.** The user tiles are twice as big (squares that wrap, no limit per row), and the button sits right next to the new picture.
- **Profile Picture: only the four `avatar` files are written** (`avatar64.dds`, `avatar128.dds`, `avatar260.dds`, `avatar440.dds`), plus the user's `online.json` with the user name and the verified flag when Home Screen Manager created that file itself (one the console made is never touched). The change shows as soon as the home screen comes back (the PlayStation button in a game, or closing it), with no restart. The other six files of a profile folder (`picture*.dds`, `avatar.png`, `picture.png`) are never changed, but they are still backed up and put back by **Use the original picture**, so pictures written by an earlier test version are undone too. This is a test of whether the four are enough.
- **Folder names stay right after a database rebuild.** When a folder tile's own file (`param.json`) still holds an old name, it is rewritten with the folder's current name, so a rebuild by the console no longer brings the old name back.

- **Home Screen Manager no longer updates itself.** Removed: **Install** from GitHub, installing from a USB drive, **Install from a file** (and Allow older versions), the restart after an update, the "updated to" note, and the check of USB drives. There is now one way to update: load the new version by hand (Payload Manager, or the app from GitHub). Update notices stay: the notice at the top of the menu and in Update settings (version and release notes) and the start-up pop-up, all for GitHub only. The notices have no links or buttons any more. The program still carries its version marker.
- **Font look (read-only).** At every start Home Screen Manager looks at `/preinst/common/font`, `/system/common/font` and `/system_ex/common/font` and writes what it finds (file names, sizes, first bytes, the mount, and whether write permission is granted; nothing is written or changed) to `/data/homescreenmanager/font_probe.txt`; the log gets one line about it. This is only to find out whether a font changer could work on a given firmware.
- **Profile picture folder look (read-only).** In the same way it looks at `/system_data/priv/cache/profile` (and, only one level deep, `/system_data/priv/cache` and `/user/home`) and writes names, sizes, modes and the first four bytes of each file (never what is inside) to `/data/homescreenmanager/profile_probe.txt`, with one log line. This is to find out where a given firmware keeps the profile pictures before an avatar changer is built.
- **Profile picture (new section).** Change the picture of any user on the console from the menu: choose the user, pick a picture (upload or from a USB drive), crop it square, and it is saved. The picture is written the way the home screen reads it: four DXT5 files (`avatar64.dds`, `avatar128.dds`, `avatar260.dds`, `avatar440.dds`) in `/system_data/priv/cache/profile/0x<user id>/`, plus an empty `online.json` only if the user has none. Nothing else is touched. The first change keeps the console's own files in `/data/homescreenmanager/avatar/<id>/`; **Use the original** puts them back byte for byte (and removes what was not there before), and **Undo everything** does it for all users. The home screen is refreshed after a change; if the old picture still shows, restart the console's home screen or the console. Pictures are encoded in full before any file is written, and files are replaced one by one through a temporary name, so a failure puts the originals back. Measured by the method's author on firmware 13.00 with an offline user; a signed-in PSN account may fetch its own picture again and overwrite this one.
- **Fixed (probably): a folder tile showing an old name.** When another tool such as PS4 Mount registers games, the console can write a folder tile's earlier name back into its database, so the tile says one thing and the folder page another. The watchdog now compares every folder tile's name with the folder's name each time it checks and puts the right one back (the log says `the console had changed the name to ... put ... back`). Only the name is touched.
- **Profile Picture: user names, smaller user tiles, round crop.** The users are listed by the name the console has for them (`User 1`, `User 2` only when the name can't be read), five to a row, smaller. The crop window for a profile picture darkens everything outside the circle the console shows (the saved picture is still the full square).
- **Fixed: Copy log could show only the last few lines.** The log is moved to `log.txt.old` when it reaches 1 MB, and right after that the log (and Copy log) held only what was written since. It now adds the end of the old file in front, so it always has up to 600 KB of history.
- **Profile Picture: several pictures per user, changed by itself.** **Add to the list** collects up to 12 pictures for a user (kept as 512 px squares in `/data/homescreenmanager/avatar/pool/<id>/`). Tap one to use it now, or press **Use this playlist** (it picks a random picture at once and shows that the list is in use; **Stop using this playlist** ends it): with two or more pictures Home Screen Manager then quietly writes another one of the list, picked at random so that every picture of the list is shown once before any comes again (a new round then starts with a different picture than the last one shown), when Home Screen Manager starts and when a game starts (not when a game closes, and not at a home screen restart). The picture is then already on disk while you play, and the console shows it when the home screen comes back: the PlayStation button in the game, or the game closing, with no restart. Starting Home Screen Manager's own app doesn't count as a game. **Use the original picture** puts the console's picture back, switches changing by itself off and keeps the list; **Undo everything** removes the list too.
- **Update check: a plain message when the console can't reach GitHub.** Instead of "Couldn't reach GitHub (error -2137657332)" the menu says that the console can't make the secure connection it needs and to look at the release page by hand. The code and the step it failed in stay in the log. A phone or PC browser still checks GitHub itself when it can.
- **Update notice wording.** The start-up notification now reads "Home Screen Manager v2.3.0 is available on GitHub and the ProsperoStore" (the line about the release page is gone) and the box in Update settings reads "v2.3.0 is on GitHub and ProsperoStore".

## 2.2.5

- **Fixed: the launcher tile could not keep Home Screen Manager running.** The new exit log put a handler on the hang-up and terminate signals, which replaced the "ignored" setting the ELF loader starts payloads with; when the tile's app closed, the signal it sent then ended Home Screen Manager. Signals that start out ignored now stay ignored, and the log says which ones.
- **Home Screen Manager starts in its own session.** It no longer shares the process group of the app or loader that started it, so the clean-up the console does when the tile's app ends (or crashes) should not take it along. The log says whether this worked (`startup: own session`). 
- **Fixed: the tile did not start Home Screen Manager when it was not running.** The launcher app took any open port 8090 for a running Home Screen Manager, but after rest mode, or after the payload was stopped, the old socket can still accept connections with nothing behind it, so the tile gave up with "running but does not answer". It now sends a small request (`/api/ping`) and only trusts a real answer; otherwise it sends its own copy to the loader and waits for that to answer. Rebuild the app with `native-app/build.sh` to get this.
- **The launcher app no longer ends when a connection is closed on it.** Its connections to Home Screen Manager and to the loader now fail with an error instead of raising SIGPIPE, which the console reports as an app crash (CE-108255-1). The trace also shows the connect, write and read of the menu request. Rebuild the app with `native-app/build.sh` to get this.
- **The launcher app writes a trace.** Every tile launch writes one line per step to `/data/homescreenmanager/hsm_launcher.txt` (whether Home Screen Manager answered, the payload chosen, the result of sending it, the wait, the last step), so an app error such as CE-108255-1 shows how far the launcher got. The app needs to be rebuilt with `native-app/build.sh` to include it.
- **Fixed: the menu stopped answering after rest mode.** The console does not end Home Screen Manager when it goes to rest mode; it keeps running, but its menu socket can be dead afterwards, so the menu (port 8090), the folders and the launcher tile got no answer (Payload Manager still listed it as running) until it was stopped and started again. The program now checks its own menu every 30 seconds and right after it has been frozen, and opens the socket again when nobody can connect (the log says `menu server: opened again`). A dead socket reported by the system is handled at once.
- **Launch marker for the sleep problem.** Every start writes one line (time and process number) to `/data/homescreenmanager/hsm_launch.txt` before anything else runs, and the log lists the recent launches. After a console sleep this shows whether Home Screen Manager was started at all. The log also says when the menu loop did not turn for 20 seconds or more (the console froze it in rest mode, or a long job).
- **Log shows a run that did not stop cleanly.** If Home Screen Manager is ended from outside (stopped in Payload Manager, a crash, the console restarting), the next start logs when it was last seen running, so the cause can be checked.
- **Where the system tiles open.** New menu section: the PlayStation Store, PlayStation Plus and Welcome tiles can open another link (a list of links, or one you type), with the console's own link saved and put back by **Use the original** and Undo everything. Home Screen Manager puts the link back at start-up if the console changed it. The home screen refreshes by itself after each change. Idea and database layout from JailbreakStore by maj0r (MIT).
- **Home screen music.** A new menu section plays your own song on the home screen. Pick a WAV or MP3 from a USB drive or upload one (up to 100 MB); Home Screen Manager converts it to ATRAC9 itself (a C port of the encoder in Prospero Themes by Darkatek7, which comes from Blaze414's ps5-theme and builds on LibAtrac9 by Alex Barney), matches the loudness to the console's own music, offers a volume slider (-12 dB to +12 dB), fades the ends so the loop doesn't click, cuts songs at 5 minutes and loops them, and plays a preview in the menu. The file info (name, length, cut, level) is shown, with a progress bar and Cancel. The result is decoded again and checked before anything is replaced, the console's file is only replaced when everything worked (a cancelled job or a console that went to sleep leaves it alone), and only `bgm_home.at9` is touched. **Use the original music** (and Undo everything) puts the console's file back; if a firmware update or another tool changed the file meanwhile, it is left as it is and the menu says so. Experimental: not confirmed on firmware 13.60, and the new music may need a home screen or console restart to be heard.
- **Folders now show in Change and Edit Wallpapers** (they were missing from the list in 2.2.4, so the bulk folder wallpaper could not be used there). New buttons **Folders only** and **System tiles only** next to Games tab only / Media tab only.
- Home screen music: the loudness reference is now the console's whole music mixed down to stereo (front, centre and surround), not only the front pair, and a measured +5 dB is added (the console's music is heard louder than it measures), so 0 dB should match the console better (the slider goes up to +12 dB). The home screen restarts by itself when the music is changed or put back; the attention message sits above the Convert button and the results show as pop-ups like elsewhere. The menu says whether the console's music could be measured.
- **Putting folder backgrounds back is quick.** Taking the backgrounds off many folders no longer runs the console's install (about 100 s, during which games moved around). The tile's picture and its database entry are removed directly.
- **Shorter log.** The long listing of system picture folders at start-up is gone from the normal log.
- **Folder backgrounds in bulk.** One install now shows the console all the changed folders together (before, only the first ticked folder was shown to it, so the others never got the new background). After the install HSM waits until the console has been quiet for 8 seconds (at most 150 s) before restarting the home screen. The log shows what the console made of each folder's pictures.
- **Folders without a background showed black first.** A folder whose background was taken away could keep a home screen database entry pointing at a picture that is gone. HSM now clears such entries (after installing folders, and at start-up) and logs what it found.
- Fixed a rare out-of-range bit shift in the new encoder (found by the test suite).

## 2.2.4

- **Bulk background for folders.** In Change and Edit Wallpapers the folders are listed as a group of their own, like games and apps (not ticked at the start, included by Select all). One picture goes on all ticked folders in one run; the folders are registered with a single install and the home screen restarts once. "Overwrite", "Use the original for the selected" and "Use the original for all" work for folders too.
- **Backgrounds for system tiles.** PlayStation Plus, PlayStation Store, TV & Video, Music, All Apps, Explore, Game Library, Media Gallery, App Library, Share Play, Disc Player, Unsupported Disc and Remote Play (13 tiles) can be given a background, one by one (Edit next to the tile) or in the bulk changer (a "System tiles" group, not ticked at the start). The console keeps these as zstd files `bg_NPXS*.dds.zst` in `/system_ex/vsh_asset`; HSM writes its picture as the same kind of file (the 3840x2160 BC7 texture the game backgrounds use, in a zstd frame of stored blocks). The first time a tile is changed its original file is copied to `/data/homescreenmanager/sysbg/<id>.orig` and is never overwritten; "Use the original" (also "Use the original for all" and "undo everything") puts it back byte for byte. A file that isn't a zstd file is left alone. Not yet tried on a console.
- **Pictures for system tiles.** PlayStation Store, PlayStation Plus, Game Library, App Library, Media Gallery, Explore, TV & Video, Music and All Apps can be given a picture in the editor (Edit next to the tile; not in the bulk changer). The console keeps these as `icon0.png` files in the tile's own folder: under `/system_ex/rnps/apps` on newer firmware, under `/mnt/rnps/apps` on firmware with live copies (that one is used when it exists). HSM writes a 512x512 PNG there through a temporary file; the first time a tile is changed its file is copied to `/data/homescreenmanager/sysicon/<id>.orig`, and "Use the original" (also "for all" and "undo everything") puts it back where it came from. A file that isn't a PNG is left alone. Not yet tried on a console.

## 2.2.1

First public release of Home Screen Manager (the renamed Home Hider). It includes everything listed under 2.2.0 in `CHANGELOG.md`.

- **Deleting a folder restarts the home screen** (once, after the same short wait as other folder changes), so the deleted tile goes at once. The console doesn't repaint by itself after a delete. (A try at redrawing without a restart was dropped: the console shows hidden games again during any install-all.)
- **One restart after a delete.** A leftover tile of the deleted folder is taken away before the restart, so the home screen isn't restarted a second time.
- **Log: install check.** Before every folder install the log says what the console can see of the tile (in its database, own folder, appmeta copy, how many apps, how long ago the same number was deleted, how long the last install took), to find out why an install is sometimes slow.
- **Native app.** The launcher app opens the menu when it starts Home Screen Manager (or when it is already running) and then closes itself without an error message. When it has to start Home Screen Manager it uses the copy that an update (from GitHub or USB) left in `/data/homescreenmanager` if that one is newer than the copy bundled in the app, so the tile follows updates without reinstalling the app.

## 2.2.0

- **Renamed to Home Screen Manager.** The data folder moved from `/data/homehider` to `/data/homescreenmanager` (copied, checked file by file, then the old one is removed; the old folder is kept if anything fails). The file is now `HomeScreenManager.elf`. Existing Payload Manager and Autoload entries keep working and are updated in place.
- **Folders.** A game can be in several folders. Folders can stay first on the home screen. The folder page can hide its picture and name, its count and sort row, and its edit link. Two new folder colours, dark gray and black.
- **Live wallpaper (LiveShell Engine) removed.** Home Screen Manager can now set its own backgrounds for games, apps and folders, so the built-in video wallpaper engine, its menu section, its settings entry and its files are gone, and the payload is smaller. If you still want video wallpapers, load LiveShell from Payload Manager on its own. A `live=` line in an old settings file is ignored. If LiveShell was running through an older Home Screen Manager it keeps running until the console restarts. Backgrounds for the system tiles (Media Gallery, App Library, Store) are still on the to-do list.
- **Three folder views, with options.** The count and sort row on the folder page has a **View** menu next to Sort by: **Icon** (the icon view, called Grid before), **Compact** (one row per game, the picture first and then the title, titles in bold) and **List** (the titles only, no pictures, in bold). A second menu to the right of it follows the view: **Tiles per row** for Icon (5 to 10, 6 is the default) and **Columns** for Compact and List (1 to 3, 1 is the default). A game name that is wider than its tile or column slides back and forth so you can read all of it, in every view. It all works with the d-pad and the mouse, and the choices are remembered like the sort.
- **Clean Up Game Names.** "Keep name as intended." is a white heading now, and Apply, Use the original names and the hand-names tick box sit together under the list of changed names, like the buttons in the wallpapers section.
- **Read-only look at the system picture folders.** At start the log lists what is in `/system_ex/vsh_asset` (every file), `/mnt/rnps/apps`, `/system_ex/rnps/apps` (and which picture files each system app has) and `/user/appmeta` (names and sizes only, lines starting with `probe:`). Nothing is changed. It shows whether this firmware has the files needed for system-tile backgrounds.
- **Folder repair double-checks first.** When folder tiles look missing, the repair now waits a moment and looks again before it reinstalls anything, and it does nothing if the home screen database does not answer properly. The log says which folders looked missing and why, so a needless re-registration (about 1½ minutes) is easier to trace.
- **Launch problems are logged.** When a game does not start, the log now has the console error code, the game that is running and the app id lookup. A "switching to" answer for the game that is already starting counts as started.
- **Leftover folder tiles are swept away.** A folder tile with no folder of ours behind it (a deleted folder, or one left by an older version) used to come back as a blank tile, for example "Miscellaneous" with "That folder doesn't exist", every time another tool such as PS4 Mount re-registered the games. Home Screen Manager now removes any HHFD tile that is not one of our folders, together with its whole directory, so it cannot return. It looks at start-up, when the home screen database has calmed down after another tool was busy in it, and every 10 minutes, never while a folder is being saved or an import runs. It logs each one it removes.
- **Folder repair waits for other apps.** Apps such as PS4 Mount or ShadowMountPlus re-register games, which makes the console hide the folder tiles for as long as they work, however many games they add. The automatic repair no longer starts its own 90-second install in the middle of that: a missing folder tile is only reinstalled when it has been missing for at least 45 seconds and the home screen database has been quiet for 30 seconds (after 15 minutes at the latest). The repair at start-up is unchanged. The menu explains that tiles can be reshuffled while another app works and that Home Screen Manager puts them back afterwards. The home screen is not restarted for this.
- **More in the diagnostics.** Two new lists: every tile on the home screen that is not a game, and every directory in the apps folder that is not a game. If a blank tile keeps coming back, it is in one of them.
- **Folders go back to their tab by themselves.** The background check that waits for other apps returned early when no folder tile was missing, so a folder tile that another tool (such as PS4 Mount re-adding a game) had moved to the Media tab was never moved back. It now puts every folder tile back on its own tab on each pass.
- **Leftover folder tiles are removed from the home screen database itself.** The console's uninstall answers success for a tile it doesn't know, but the tile's rows stay in the database, and the next install-all by another tool (PS4 Mount) shows the tile again, as a blank tile with an old folder name. The cleanup, and deleting a folder, now also delete those rows (tile, concept and content entries of our own folder tiles only).
- **Leftover folder tiles: the console's second copy is removed too, and the log says what was found.** A leftover tile kept coming back after it was swept, so the cleanup (and deleting a folder) now also removes the copy of the tile's data the console keeps under appmeta. For every leftover it logs whether the directory, the appmeta copy and the tile in the home screen database were there, and whether the tile is still in the database afterwards.
- **Home Screen Manager names its process.** It now sets its process name to "HomeScreenManager" at start-up, so a payload manager can list it as running instead of only showing "payload pid N". Whether a manager shows it depends on which name that manager reads.
- **Clean Up Game Names also fixes capital words inside a name that has both cases.** Before, a name was only changed when it was all upper case or all lower case, so "RESIDENT EVIL requiem" or "WUCHANG: Fallen Feathers" were left alone. Now a word of four or more capital letters in such a name is fixed (Resident Evil Requiem, Wuchang: Fallen Feathers); in such a name the plain lower case words get capitals too, with the small words (of, the, and) kept small. Shorter capital words (GTA, NBA), Roman numerals, words with digits and the names you keep as written stay as they are. These names show up in the same list of changed names as all the others, with no extra tick box.
- **Folder tiles install in seconds, whatever the size of the library (PS4 Mount's method).** On this firmware the only way to register a tile is the console's install-all, which walks every game folder (about 0.7 s per game): 90 seconds and more with a big library. Now the console is shown an empty staging folder over /user/app with only the new tile mounted into it for the install, then everything is put back. Not done while a game runs or when /user/app is already covered by something else; any failure falls back to the normal install, and a covered /user/app left by an interrupted run is restored at start-up.
- **Five folder picture styles.** Under Folder picture you can choose how the folder's picture is laid out from its games: Grid 2×2, Grid 3×3, Stack, Feature (one big game with small ones next to it) or Single. A live preview shows the result as you pick. The style is saved per folder and is part of backup export and import.
- **Crop and zoom window for every picture.** Wherever a picture is chosen (folder picture and background, game picture and background, the bulk background, from the phone/PC or from a USB drive) a window opens first: drag to move, mouse wheel, slider, + and − or a pinch to zoom, with thirds guides. On the controller press Enter to switch to move mode and use the arrows. Choose Use this crop, Use without cropping, or Cancel. USB pictures are fetched through a new `/api/usb_pic`.
- **A new folder with a picture or background is installed once, not two or three times.** The page used to save the folder, then upload the picture, then the background, and each step ran its own install (95 seconds each on a big library). Now the first steps only write the files and the last step installs the tile. On a failed step the missing tile is put back by the automatic repair.
- **The fast install says why it was not used.** In build 6 it never started and the log did not say why. The "is a game running" check looked at any system sandbox mount, which always exist; it now asks the console which game is open, like PS4 Mount. The log names the reason whenever the fast install is skipped, and shows what /user/app is mounted on.
- **The fast install waits for PS4 Mount.** If another tool is showing only its own new games over /user/app (PS4 Mount does this for about 8 seconds per batch), the covers could overlap. Home Screen Manager now waits up to a minute for the other cover to go before putting its own on, and when it takes its own away it leaves a cover that another tool put on top alone.
- **Folder installs wait for other tools to finish.** Before a folder tile is installed, Home Screen Manager looks at the home screen database and the apps folder; if another tool (PS4 Mount, ShadowMount+, the console) is still changing them, it waits until they have been still for 4 seconds, for 30 seconds at most (not at all while a game is open), so its own install never lands in the middle of another tool's install-all. On a quiet console this costs one second.
- **The folder page has a new order:** name, tab, games, then colour, folder picture and the home screen background, then the attention message and the buttons.
- **The preview cache keeps the newest.** Over 600 files or 40 MB, the oldest previews are removed down to 75% instead of emptying the whole folder.
- **A game that fails in a bulk background run is named in the log** (it was only in the pop-up message before), with the reason.
- **Import no longer stops Home Screen Manager at a game without a background entry.** Filling a background in such a game needs a big thread stack, and the import ran on a small one (the bulk background run already had the big one). On the console the program stopped right there, so everything after that game was not restored. The import now runs on the same big stack.
- **Import keeps track of which names came from Clean Up Game Names.** Before, every custom name came back from an import as a name you gave by hand, so Clean Up Game Names then treated all of them as yours. The backup now records which names came from the cleanup, and the name you gave by hand before it, and import restores both. Backups made with an earlier version do not have this, so their names still come back as yours.

- **Import fills games without a background entry.** A background in a backup for a game that has no background entry of its own (the games the tools fill in) is now restored the same way the tools set it, so import no longer reports "This tile has no background in the home screen database" for them. The import result keeps room for all its problem notes, not just the first few.
