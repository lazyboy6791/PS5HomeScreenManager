Home Screen Manager

Take control of your PlayStation 5's home screen

Home Screen Folders and Tiles

Your games, apps and folders, grouped by the tab they sit on. Press Edit on any one to rename it, change its picture or background, or move it to the other tab. New folder groups games under one tile.

Folder options
Keep folders first
Your folders stay in the first spots of their tab, ahead of every game and app, even after you play something else. The folder you open still moves to the front of the folders. Turn off to let the PS5 order everything by recent play.
Folder page: show the name and picture
Shows the folder's picture and name at the top of its page.
Folder page: show the count and sort row
The line above the games with how many there are and the Sort by button. Turn off to show just the games; the sort order you chose last stays in use.
Folder page: show the edit link
The small "Edit this folder in Home Screen Manager" text under the games on the folder page. Turn off to hide it; you can still edit a folder from the Home screen list.

Tile hiding options
Keep tiles hidden
If the PS5 brings a hidden tile back — after an update, or after you play a game that was inside a folder — Home Screen Manager hides it again by itself, every few seconds while it's running. Turn off to leave the PS5's changes alone.
Show a running game
While a game that is hidden (for example one inside a folder) is running, its tile stays on the home screen, in front of the folders, so you can close it from the home row. It is hidden again after you close the game. Turn off to hide it straight away.
Change and Edit Wallpapers

Use one still picture as the background of many games at once. The home screen shows it behind the games while a game is highlighted. Home Screen Manager converts the picture once and shares the result between the games. Folders and games without a background entry are left out.

One converted file for all the games, kept in a folder of its own. Try it on a few games first, restart the console once, and check that the backgrounds are still there.
!ATTENTION! Applying or undoing a background for many games can take a while. Please do not open any apps or games while it runs. When it has finished, the homescreen will refresh automatically to show the results.

Home Screen Manager Start-Up Options
Update settings
Checking for updates…
GitHub repository
Where new versions are published, for example yourname/HomeScreenManager. The latest release needs a HomeScreenManager .elf attached.
Check for updates when Home Screen Manager starts
Looks on GitHub and on USB drives. Nothing is installed until you press Install.
Install from a file
Pick a HomeScreenManager .elf on this phone or PC. To update from a USB drive instead, copy the .elf to the drive's top folder (or a folder named homescreenmanager) and press Check for updates.
Export & Import

Saves everything Home Screen Manager manages in one file: your folders with their pictures and backgrounds, the tiles you hid, custom names, pictures and backgrounds, the home screen order and the settings. Your games are not in it, and the original database backup stays a separate download.

Download to this phone or PC
Import Experimental
!ATTENTION! Experimental: the import hasn't been tested on a console yet. Export your current setup first, so you can go back. Importing can take up to 10 minutes to import and install everything, depending on your firmware. Please do not open any apps or games while it runs. The homescreen will refresh automatically when it is done.

Import adds the backup's folders next to the ones you have, hides the tiles it lists and restores the custom names, pictures and backgrounds. It replaces your saved home screen order and your settings with the backup's. Games that aren't installed on this console are skipped.
